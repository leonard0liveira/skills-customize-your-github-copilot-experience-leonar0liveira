
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Criar o jogo da Forca

#### Descrição

Implemente um jogo em que o jogador adivinha letras para revelar uma palavra oculta antes de esgotar o número permitido de tentativas.

#### Requisitos

O programa concluído deve:

- Selecionar uma palavra aleatoriamente a partir de uma lista predefinida.
- Aceitar palpites de letras e exibir o progresso atual no formato `_ _ _`.
- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas.
- Exibir uma mensagem informando se o jogador venceu ou perdeu.
